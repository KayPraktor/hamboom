# @hamboom/canvas-core

موتور بوم هم‌بوم — رندر، عناصر، ابزارها و قرارداد همگام‌سازی.

این پکیج **کاملاً آفلاین** است: هیچ شبکه‌ای، هیچ Yjs، هیچ احراز هویتی. تنها راه
ارتباط با دنیای بیرون، پیاده‌سازی `CanvasSyncAdapter` است که ماژول `realtime-sync`
فراهم می‌کند.

```
┌──────────────────┐   ElementChangeSet   ┌─────────────────┐
│   canvas-core    │ ───────────────────▶ │  SyncAdapter    │
│  (این پکیج)      │ ◀─────────────────── │  (ماژول M2)     │
└──────────────────┘   PeerState، وضعیت    └─────────────────┘
        بدون شبکه                              با شبکه
```

## نصب و اجرا

```bash
pnpm --filter @hamboom/canvas-core dev
```

دمو روی `http://127.0.0.1:5180` بالا می‌آید.
