# engine/

wrapper روی موتور رندر Excalidraw و هر چیزی که مستقیماً با آن حرف می‌زند.

**اینجا می‌آید:** `HamboomCanvas.tsx` (کامپوننت اصلی)، گرفتن و مدیریت `excalidrawAPI`،
gate بارگذاری فونت، پل بین state موتور و لایه‌ی هم‌بوم، culling و تنظیمات کارایی.

**اینجا نمی‌آید:** منطق محصولی عناصر (→ `elements/`)، رابط کاربری (→ `ui/`).

**قاعده:** تنها پوشه‌ای که اجازه‌ی import مستقیم از `@excalidraw/excalidraw` را دارد
`engine/` و `elements/mapping.ts` است. بقیه‌ی کد باید از انتزاع‌های همین پوشه استفاده کند —
تا اگر روزی به پله‌ی fork رفتیم ([ADR-003](../../../../ARCHITECTURE_DECISIONS.md#adr-003))،
سطح تماس محدود بماند.
