# text/

همه‌چیزِ متن فارسی روی بوم. **پرریسک‌ترین بخش این ماژول.**

**اینجا می‌آید:** `font-registry.ts` (ثبت Vazirmatn + `awaitFontsReady()`)،
`bidi.ts` (`detectBaseDirection`, `isRTLChar`, `normalizePersian`)،
`measure.ts` (اندازه‌گیری با کش)، منطق شکست خط سازگار با لیگاتور.

**چرا جداست:** رندر متن روی canvas — برخلاف DOM — شکل‌دهی حروف، ترتیب bidi و
شکست خط را خودکار حل نمی‌کند. جدا نگه داشتن این منطق باعث می‌شود اگر مجبور به
patch یا fork شدیم، دقیقاً بدانیم چه چیزی را جایگزین می‌کنیم.

**قاعده:** اندازه‌گیری متن باید **بعد از** `document.fonts.ready` انجام شود، وگرنه
عرض‌ها با فونت fallback حساب می‌شوند و متن بعداً می‌پرد
([ADR-017](../../../../ARCHITECTURE_DECISIONS.md#adr-017)).
