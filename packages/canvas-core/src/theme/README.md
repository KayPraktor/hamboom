# theme/

پالت و توکن‌های ظاهری — «استایل میرو» در برابر «استایل دست‌نویس Excalidraw».

**اینجا می‌آید:** `sticky-palette.ts` (۱۲ رنگ با `bg`/`text`/`accent`)،
`tokens.ts` (رنگ رابط، شعاع، سایه، فاصله، اندازه‌ی فونت)،
`defaults.ts` (پیش‌فرض عناصر).

**کلید ظاهر میرو-استایل:** `roughness: 0` + `fillStyle: "solid"` + `roundness: {type:3}`.
همین سه مقدار تفاوت بصری اصلی با Excalidraw پیش‌فرض را می‌سازند.

**قاعده:** هر جفت `bg`/`text` باید کنتراست ≥ 4.5:1 داشته باشد (WCAG AA) و یک تست
خودکار این را تضمین می‌کند. رنگ‌های PLAN.md بازسازی سلیقه‌ای در همان خانواده‌ی رنگی‌اند،
نه کپی از توکن‌های میرو.
