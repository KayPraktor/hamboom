# CLAUDE.md — `@hamboom/config`

خواندن و اعتبارسنجیِ متغیرهای محیطی. **پایین‌ترین لایه‌ی پروژه** — همه رویش سوارند.

**قبل از کار بخوان:** [PLAN.md بخش ۴](../../PLAN.md) (فهرستِ کاملِ متغیرها) و
[`.env.example`](../../.env.example) (تنها منبعِ حقیقتِ نامِ متغیرها).

> ⚠️ این پکیج **برشِ حداقلیِ M2** است (تصمیمِ D-1). فقط بخش‌هایی را دارد که الان
> مصرف‌کننده دارند. M5 کاملش می‌کند و M3/M4 بخش‌های خودشان (S3، احراز هویت، پیامک،
> زرین‌پال) را از PLAN بخش ۴ اضافه می‌کنند.

## خط قرمزها

1. ★ **تنها جایی در کل ریپو که `process.env` خوانده می‌شود.** قاعده‌ی ESLintِ
   `processEnvDiscipline` بقیه را خطا می‌کند — بدونِ استثنا، حتی برای `NODE_ENV`
   (اولین استثنا در عمل کلِ قاعده را باز می‌کند).
2. **schema ترکیب‌پذیر بماند، یکپارچه نشود.** هر اپ فقط بخشِ خودش را لازم دارد. اگر
   یک schema بزرگِ واحد بسازیم، `apps/realtime` برای بالا آمدن به
   `ZARINPAL_MERCHANT_ID` هم نیاز پیدا می‌کند — و اولین کاری که هرکس می‌کند گذاشتنِ
   یک مقدارِ الکی است تا رد شود. از آن لحظه گیت مرده است.
3. **fail-fast در بوت، نه وسطِ کار.** خطا باید **نامِ متغیر** را بگوید و به
   `.env.example` ارجاع بدهد؛ وگرنه پیام بی‌فایده است.
4. ★ **برای بولین هرگز `z.coerce.boolean()` ننویس.** `Boolean("false") === true`
   است، یعنی `DATABASE_SSL=false` بی‌صدا `true` می‌شود. فقط دو رشته‌ی صریح
   (`envBoolean`). یک تست این را قفل کرده.
5. **این پکیج به هیچ پکیج هم‌بومِ دیگری وابسته نیست** — همه رویش سوارند.

## ★ تله: پسوندِ `.ts` روی importهای نسبی

این پکیج **مستقیماً با Node اجرا می‌شود** (`node scripts/migrate.ts`، و در فاز ۴
خودِ `apps/realtime`). برخلاف Vite، Node پسوند را حدس نمی‌زند:

```ts
export { loadEnv } from "./load";      // ❌ ERR_MODULE_NOT_FOUND در Node
export { loadEnv } from "./load.ts";   // ✅
```

به همین دلیل `allowImportingTsExtensions: true` در `tsconfig.json` این پکیج (و در
`tsconfig.json` ریشه، چون اسکریپت‌ها همین را مصرف می‌کنند) روشن است. همین قاعده برای
`ydoc-schema` و `apps/realtime` هم صدق می‌کند — هر سه مصرف‌کننده‌ی Nodeِ خالص‌اند.
(این همان چیزی است که `canvas-core/CLAUDE.md` پیش‌بینی کرده بود: «اگر روزی یک
مصرف‌کننده‌ی Node خالص اضافه شد…».)
